## Project Relevance

Lakoff identifies a set of linguistic features — hedging, qualifiers, tag questions, rising intonation on declaratives — that she associates with social powerlessness. The paper draws on this work as the precursor to O'Barr and Atkins's (1980) powerless speech construct, which reframes these features as markers of low institutional power rather than gender.
