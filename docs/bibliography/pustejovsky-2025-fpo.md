## Project Relevance

This is the foundational technical paper for the FPO framework, which defines the five friction components (uncertainty/miscalibration, contradiction, hazard, value conflict, and information gain) and the formal apparatus for intervention policy optimization. It is the primary computational antecedent the project extends — the argument throughout the writeup is that FPO's epistemic scope must be broadened to handle the full dimensionality of interpersonal conflict, and every proposed extension is in dialogue with this paper's architecture. *Note: the filename suggests submission to Transactions of the Association for Computational Linguistics (TACL); as of writing, treat as an unpublished manuscript under review and characterize accordingly in the writeup.*
